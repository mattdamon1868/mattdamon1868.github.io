# Dylan James-Kavanaugh: Portfolio

Live site: **https://mattdamon1868.github.io**

I'm a robotics engineer with a background in mechatronics and mechanical engineering, spanning controls, autonomous systems, and computer vision most recently a Graduate Research Assistant at San Diego State University's DSIM Lab, working on extremum seeking control for autonomous source-seeking robots. This site holds my CV, publications, portfolio, work experience, and teaching history.

## Running locally

```bash
docker compose up --build
```

Then visit `http://localhost:4000`.

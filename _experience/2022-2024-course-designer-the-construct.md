As a freelance Course Designer for The Construct, I optimized and debugged ROS2 and Gazebo simulation environments to create engaging, intuitive learning experiences for students, aligning simulations with students' learning curves so environments were both challenging and approachable.

One of my key contributions was designing and implementing an image recognition system for a simulated security robot. Using convolutional neural networks (CNNs), I built a framework that let the robot identify and classify objects within a virtual environment, using ROS2 for communication between the robot's perception and decision-making systems and Gazebo to create a realistic testing area for students.

This hands-on setup demonstrated the synergy between computer vision and robotics while giving students a practical, scalable way to experiment with deep learning in a robotics context.

**Skills:** Python, programming, computer vision, deep learning, ROS2
